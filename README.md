# 评论组件 Next 皮肤

为「评论组件 Next」提供评论区样式修改的 Halo 插件，安装启用后立即生效。

## 外观

- 配色全部取自主题令牌：强调色用 `--primary`，卡片用 `--card-bg`，浮层用 `--float-panel-bg`，分隔线用 `--line-divider`，正文用 `--deep-text`。换主题色、切深浅色都不用改插件。
- 卡片沿用主题的 1rem 圆角、1px 发丝描边和 `0 1px 2px` 阴影；按钮、输入框统一 10px 圆角。
- 排序切换做成与主题分段控件一致的样子：浅色主题色轨道加实心主色选中块，切换时不闪。
- 分页按钮 10px 圆角，当前页实心主色，禁用态降到 38% 透明度。
- 评论输入框为 1rem 圆角卡片，聚焦时出现主色描边和 14% 光晕。
- 表情面板使用浮层底色、1rem 圆角和浮层阴影；电脑端与移动端默认都完整露出三行表情，不多不少；分类栏停靠在底部，分类按钮左侧带该分类第一张表情的缩略图（「最近」除外），每页固定 30 个表情。
- 表情换页按钮跟在网格后面、留在滚动层里，滑到底才出现，不再挤压最后一行的表情；翻页和切换分类后内容回到顶部。
- 表情搜索框换成 Material Symbols 的放大镜图标，颜色跟随次要文字色。
- 表情悬停预览关闭，避免浮层跟随鼠标时遮挡内容。
- 评论区没有评论时显示一块虚线占位卡片（图标 + 「还没有评论」），不再是一行裸文字。
- 「选择评论身份」「当前评论身份」和「游客资料」弹窗复用评论输入框的圆角、描边与主色按钮，当前身份显示为一张头像 + 昵称 + 身份的小卡片。

## 安装

1. 在 Releases 下载 `plugin-comment-skin-1.1.6.jar`。
2. Halo 控制台 → 插件 → 安装，上传 JAR 后启用。
3. 无需任何配置。

## 环境要求

- Halo 2.27.0 及以上。
- 已安装并启用「评论组件 Next」。
- 前台主题需提供 Ethereal 的设计令牌；缺少令牌时退回中性蓝灰配色，功能不受影响。

## 说明

评论组件把内容渲染在 Shadow DOM 里，页面级样式进不去，所以插件做两件事：向页面注入一组自定义属性，再向每个评论组件的 Shadow Root 追加一份样式表。脚本不改评论数据、不拦截评论请求，评论区之外的页面元素不受影响；站点没有评论组件时，插件不做任何事。

配色只做映射，不写死色值：Ethereal 在 `:root` 上定义 `--primary`、`--card-bg`、`--deep-text` 等令牌，并随 `data-hue` 与 `.dark` 变化；插件在 `comment-widget` 上把这些令牌换算成自己的一套变量，卡片、按钮、面板和深浅色因此都跟着主题走。

另外两处行为由脚本完成，都只作用于前台页面：

- 分类缩略图：读取评论组件自己的表情配置接口，取每个分类第一条表情的图片地址，插到分类按钮的文字前面。
- 每页表情数：评论组件的设置里允许 1–100，脚本在读取配置时把 表情每页数量 固定为 30，其他设置原样透传。

## 构建

需要 JDK 21：

```bash
./gradlew build
```

产物位于 `build/libs/plugin-comment-skin-<version>.jar`。
