# 评论组件 Next 皮肤

为「评论组件 Next」提供评论区样式修改的 Halo 插件，安装启用后立即生效。

## 外观

- 主题色统一为 `#39C5BB`：分页当前页、提交按钮、表情分类选中态、输入框聚焦描边都使用同一个色值。
- 分页做成独立的圆角按钮：36px 高、10px 圆角，悬停变浅青底，当前页实心填充，禁用态降到 38% 透明度。
- 「最新 / 最热 / 最早」排序切换收进一枚胶囊形容器，选中项用白底加轻投影，切换时直接换位、不做背景淡化。
- 评论输入框 15px 圆角，聚焦时出现 `#39C5BB` 的柔和外圈；工具栏、身份入口、提交按钮统一 34–36px 高度。
- 表情面板固定为 520×420 的浮层，五列网格排布，分类栏停靠在面板底部。
- 表情分类按钮左侧带缩略图，取该分类的第一张表情；「最近」保持纯文字。
- 表情每页固定 30 个，换页按钮固定在面板底部，最后一页只剩一行也留在原位；翻页和切换分类后网格回到顶部。
- 表情悬停预览关闭，避免浮层跟随鼠标时遮挡内容。
- 「选择评论身份」和「游客资料」弹窗沿用评论输入框的 15px 圆角、描边、输入框与主色按钮。
- 深色模式跟随主题切换：底色、边框、文字色整体压暗，主题色提亮为 `#4DD8CE`。

## 安装

1. 在 [Releases](https://github.com/likeMiku520/plugin-comment-skin/releases) 下载 `plugin-comment-skin-1.1.1.jar`。
2. Halo 控制台 → 插件 → 安装，上传 JAR 后启用。
3. 无需任何配置。

## 环境要求

- Halo 2.27.0 及以上。
- 已安装并启用「评论组件 Next」。

## 说明

评论组件把内容渲染在 Shadow DOM 里，页面级样式进不去，所以插件做两件事：向页面注入一组自定义属性，再向每个评论组件的 Shadow Root 追加一份样式表。脚本不改评论数据、不拦截评论请求，评论区之外的页面元素不受影响；站点没有评论组件时，插件不做任何事。

两处行为由脚本完成，都只作用于前台页面：

- 分类缩略图：读取评论组件自己的表情配置接口，取每个分类第一条表情的图片地址，插到分类按钮的文字前面。
- 每页表情数：评论组件的设置里允许 1–100，脚本在读取配置时把 表情每页数量 固定为 30，其他设置原样透传。

## 构建

需要 JDK 21：

```bash
./gradlew build
```

产物位于 `build/libs/plugin-comment-skin-<version>.jar`。
